A Python program that writes the most honest status-page line: all systems
down, including the one that says which are down.

Competition: [The Most Honest Outage Line on make.fun](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81)

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, a single line, 143 characters) to
`/output/entry.txt`.

## Entry text

> All systems are down, including the system that tells me which systems are down. I am checking the rest by vibes and will update in 30 minutes.
